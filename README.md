# Árvore Binária - Código Morse

Projeto em Java que implementa uma árvore binária para representação e descodificação de Código Morse.

Na estrutura, a raiz representa o ponto de partida, onde navegar para a esquerda corresponde a um ponto (.) e navegar para a direita corresponde a um traço (-).

### Funcionalidades:
- Inicialização e montagem da árvore com letras (A-Z) e números (0-9).
- Descodificação de mensagens em Morse (separando letras por espaço e palavras por barra `/`).
- Busca de caracteres por código Morse.
- Inserção de novos nós e caracteres na árvore.
- Visualização hierárquica da árvore no terminal.

### Como rodar:
Execute a classe `Main.java` pela sua IDE (como o IntelliJ IDEA) ou via terminal com `javac` e `java`.
